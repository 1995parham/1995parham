Every starred repository, with the list it sits in today and the list it is proposed to move to. Filter, search, and spot-check the filing before any of it is applied.

How to read this

list is where a repo sits today. list is a proposed filing for a repo that is currently in no list — list marks one of the five newly proposed lists. cut flags an unstar candidate, and review marks a repo with no description and no topics, which no rule could place.

Nothing here is applied yet. Repos already filed by hand are shown unchanged — the plan only touches repos in no list, because updateUserListsForItem replaces a repo's entire list set rather than adding to it.
